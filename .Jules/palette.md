## 2026-06-23 - Accessibility and Micro-UX Polish
**Learning:** For countdowns or time-until displays, the UI uses conditional logic (e.g., ${minsUntil} ${minsUntil === 1 ? 'min' : 'mins'}) to ensure correct pluralization. The application distinguishes 'Live' predictions from 'Scheduled' times using WCAG-compliant background colors #1b7a43 (Green) and #206694 (Blue) respectively. Using an aria-live="polite" region on the main departure display ensures screen reader users receive updates. The schedule filtering logic must use an inclusive check (m >= currentMinute) to avoid hiding departures occurring within the current minute.
**Action:** Always provide ARIA labels or visually hidden labels (sr-only) for color-coded status information. Ensure time-based logic handles edge cases like "Due now" and pluralization.
